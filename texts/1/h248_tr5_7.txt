<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Команда SeviceChange может использоваться на окончаниях для того чтобы вводить и выводить из обслуживания. Для вывода портов из обслуживания MGC передает к AG транзакцию 86173 с действиями для нулевого и 17 контектов. Для принудительного вывода окончания из обслуживания в дескрипотре Services параметр ServiceChangeMethod должен иметь значение принудительная смена (Forced). В случаях когда, есть возможность завершить соединение, а потом вывести из обслуживания окончание используется постепенный вывод из обслуживания, для которого в дескрипотре Services параметр ServiceChangeMethod должен иметь значение постепенная смена (Graceful), так же указываются параметры ServiceChangeReason - вывод окончания из обслуживания (905 Termination taken out of service) и, в некоторых случаях, ServiceChangeDelay - с указанием периода времени (в секундах), после которого окончание должно будет выведено из обслуживания.</text>
