Для передачи речевой информации между портом RTP и портом тракта Е1 необходимо создать контекст, в который будут входить свободный канал уже известного физического окончания и виртуальное окончание, назначенное шлюзом. Для создания контекста MGC передает транзакцию, в которой идентификатору ContextID присваивается значение $ (CHOOSE, произвольный). Контекст содержит две команды Add (Добавить). Первая команда Add создает новый контекст и добавляет к нему окончание с TerminationID tdm/sr17/br1/е1_7/$ (любой свободный канальный интервал 7-ого тракта е1 на 1-ой плате 17-ой полки). Вторая команда Add (TerminationID с значением $) создает виртуальное окончание и добавляет его к контексту, созданному предыдущей командой. Дескриптор Media и вложенный LocalControl назначают режим работы окончаний на прием и передачу (SendReceive), то есть в дуплексном режиме. Для виртуального окончания дескриптор LocalControl содержит в сетевом пакете (nt) параметр размер джиттер буффера 40 мс (jit). Во второй команде дескриптор Media содержит вложенный дескриптор Local, описывающий параметры медиа-сессии. Для описания медиа-сессии используется протокол описания сессий SDP (ETF RFC2327). Пример синтаксиса SDP: &quot;v&quot; - Version (версия протокола), &quot;о&quot; - Origin (идентификатор создателя сеанса), &quot;s&quot; - Session name (имя сеанса), &quot;c&quot; - Connection (данные о соединении), &quot;m&quot; -Media (поле описания медиа-данных) и др. В данной команде &quot;c&quot; содержит тип сети Интернет (IN) и тип используемой адресации (IP4) и IP адрес, пока любой ($, CHOOSE), а параметр медиа информации &quot;m&quot;- тип медиа данных в потоке RTP (audio), транспортный порт RTP, на который отправляется поток данных, пока любой ($, CHOOSE), протокол перноса медиа-информации с указанием его профиля (RTP/AVP, AVP (Audio and Video profile), предлагаемый формат медиа информации, то есть тип кодека (4 8 15), 4 - кодек G.723, 8-PCMA, 15-G.728. Так же могут быть указаны другие форматы, например: 0-PCMU, 1,2-Reserved, 3-GSM, 5,6-DVI4(8кГц,16кГц), 7-LPC, 8-PCMA, 9-G.722, 15-G.728, 18-G.729, 31-H.261(90кГц), 34-H.263(90кГц).</text>
