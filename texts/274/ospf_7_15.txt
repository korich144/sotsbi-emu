<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1496755436">LSA5 - AS-external-LSA передается ASBR и описывает внешние для AS доступные сети. Каждый LSA описывает маршрут к простому префиксу адреса IPv6. LSA5 может применяться для описания маршрута по-умолчанию, в таком случае поле PrefixLength устанавливается в нулевое значение.LSA5 содержит следующие поля:* Бит E (external) - значение 1 указывает на внешнюю метрику тип 2, что означает что метрика имеет значение больше, чем любой путь внутри автономной системы. Нулевое значение говорит о том, что внешняя метрика имеет тип 1, это означает что метрика выражена в тех же единицах измерения как и в других LSA (т.е. единицах измерения стоимости интерфейса в LSA1).* Бит F (forwarding) - установленный в 1, означает что LSA5 содержит необязательное поле Forwarding Address.* Бит T (tag) - - установленный в 1, означает что LSA5 содержит необязательное поле External Route Tag.* Поле Metric - задает стоимость маршрута. Метрика задается в тех же единицах измерения, что и стоимость интерфейса в LSA1. * Поле PrefixLength - задает число бит в префиксе.* Поле PrefixOptions размером в 8 бит описывает различные возможности связанные с префиксом.* Поле Address Prefix - содержит закодированный префикс, кратный 32-битным словам. При необходимости заполняется нулевыми битами. * Поле Referenced LS Type - если имеет ненулевое значение, то LSA с  типом LS связаны с этим LSA.* Поле Forwarding address - содержит 128 битный IPv6 адрес. Поле включается в LSA5, когда установлен флаг F. Когда указывается этот адрес, то данные в анонсированную сеть передаются на этот адрес. Поле не должно содержать неспецифицированный IPv6 адрес (0:0:0:0:0:0:0:0) или локальный IPv6 адрес интерфейса (префикс FE80/10).  Маршруты OSPFv3 обычно используют локальный адрес интерфейса, а анонсирование в OSPFv3 применяющее поле адреса пересылки (forwarding address) должно использовать глобальный IPv6 адрес. В качестве глобального адреса может использоваться соседний шлюз (next-hop gateway) для внешнего префикса или может быть получен другим способом (например, настройкой).* Поле External Route Tag - позволяет применять 32 бита для передачи дополнительной информации между ASBR. Поле включается в LSA5, когда установлен флаг T.* Поле Referenced Link State ID - включается в LSA5, когда поле Reference LS Type имеет ненулевое значение. Когда указывается это поле, то дополнительную информацию, про анонсируемый внешний маршрут, можно найти в LSA, имеющей тип LS указанный в Referenced LS Type, и Link State ID указанный в Referenced LS ID, и AR как указанный в заголовке LSA5. Эта дополнительная информация не используется OSPF протоколом, а применяется при общении между ASBR.Если перечисленные необязательные поля присутствуют в LSA5, то они должны быть расположены, в том порядке, как они были описаны.</text>
