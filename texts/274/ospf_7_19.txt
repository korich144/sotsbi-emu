<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1496399591">LSA9 - Intra-Area-Prefix-LSA применяется для анонсирования одного или более префиксов адресов IPv6 связанных с маршрутизатором, присоединенной тупиковой сетью (Stub network) или транзитной сетью, вместе с метрикой каждого префикса. IPv4 адреса в OSPFv2 передаются LSA1 или LSA2, однако в OSPFv3 для IPv6 вся адресная информация убирается из LSA1 и LSA2, и поэтому применятся LSA9. Маршрутизатор может передавать LSA9 для каждого маршрутизатора или транзитной сети, маршрутизатор источник с указанием своего идентификатора состояния канала (Link State ID).LSA9 содержит поля # prefixes, Referenced LS type, Referenced Link State ID, Referenced Advertising Router, PrefixLength, PrefixOptions, Address Prefix и Metric. Referenced LS type, Referenced LS ID and Referenced Advertising Router определяют LSA1 или LSA2, с которыми должны быть связаны префиксы адресов IPv6. Когда указывается Referenced LS type - тип 1, то префиксы связаны с LSA1, и Referenced LS ID должно иметь нулевое значение, а Referenced Advertising Router задано как Router ID маршрутизатора отправителя LSA. А когда Referenced LS type - тип 2, то префиксы связаны с LSA2, и Referenced LS ID определяет Interface ID канала DR, а Referenced Advertising Router задано как Router ID DR.* # prefixes - число префиксов IPv6 адресов содержащихся в LSA. * Поля PrefixLength, PrefixOptions и Address Prefix соответствуют LSA3.* Поле Metric - задает стоимость маршрута. Метрика задается в тех же единицах измерения, что и стоимость интерфейса в LSA1.</text>
