<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1496744837">Пакеты OSPF тип 2 содержат описание базы данных (Database Description) и передаются при инициализации смежности, для описания LSDB. Для передачи содержимого базы данных  используется процедура опроса-ответа (poll-response). DR отправляет DD опрос, на который опрашиваемый маршрутизатор отвечает сообщением DD с описанием LSDB, указывая порядковый номер опроса (DD sequence numbers).Формат пакета DD похож на формат пакетов LSR и LSA, описывая фрагмент LSDB.* Поле Interface MTU - определяет максимальный размер IP-пакета в байтах, который может быть отправлен с связаного интерфейса, без фрагментации. При передачи по виртуальным каналом поле устанавливается в нулевое значение для DD.* Поле дополнительных возможностей (Options) * Бит  I-bit (Init) - устанавливается в 1, когда пакет является первым в последовательности DD-пакетов.* Бит M-bit (More) - устанавливается в 1, когда последуют дополнительные DD-пакеты.* Бит MS-bit (Master/Slave) - установленный в 1, означает что маршрутизатор является ведущим (master) в процедуре обмена БД (Database Exchange). Нулевое значение определяет, что маршрутизатор ведомый (slave).* Поле DD sequence number - используется для накопления DD-пакетов. Начальное значение должно быть уникальным, на него указывает I-бит (Init). Порядковый номер увеличивается до тех пор, пока не будет отправлено полное описание БД.* LSA Headers. Прочие заголовки LSA содержат частичное описание LSDB. Каждый LSA в БД описывается заголовком LSA, который был описан в главе 7. Заголовок LSA содержит всю информацию необходимую для однозначной идентификации LSA и текущих значений LSA в БД.</text>
