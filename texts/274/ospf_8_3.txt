<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1496405168">Пакеты OSPF тип 1 содержат приветствия (Hello) для передачи через все интерфейсы, на которых активирован OSPF и обнаружения соседей, после договоренности об определённых параметрах, указанных в hello-пакетах.* Поле сетевой маски (Network mask) связанной с интерфейсом с которого передается hello-пакет. * Поле таймера HelloInterval задающее число секунд через которые маршрутизатор передает hello-пакеты.* Поле дополнительных возможностей (Options)        * Поле приоритета маршрутизатора (Router Priority, Rtr Pri) применяемое при выборах DR и BDR. При нулевом значении поля, маршрутизатор не будет назначаться DR или BDR.* Поле таймера RouterDeadInterval указывает число секунд после которых молчаший маршрутизатор будет считаться выключенным.* Поле DR (Designated Router) определяющее DR для данной сети с точки зрения отправляющего маршрутизатора. DR обозначается по IP адресу интерфейса для данной сети. Если DR отсутствует, то поле задается как 0.0.0.0 .* Поле BDR (Backup Designated Router)  аналогично полю DR, но для обозначения BDR.* Поле соседей (Neighbor) содержит Router ID для каждого маршрутизатора передающего корректные hello-пакеты. Согласно RouterDeadInterval.</text>
