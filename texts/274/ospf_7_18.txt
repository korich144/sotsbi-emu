<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1496239136">LSA8 - Link-LSA передается маршрутизатором для каждого конкретного канала. LSA8 распространяется только в конкретном канале, и никогда не передается между каналами. LSA8 применятся для предоставления локального адреса другим присоединенным маршрутизаторам по каналу, для информирования других маршрутизаторов присоединенных по каналу о списке IPv6 префиксов канала, для утверждения набора бит поля Options в LSA2 (Network-LSA), передаваемых по данному каналу. Поле Link State ID в LSA8 содержит идентификатор интерфейса маршрутизатора передающего LSA8.* Поле приоритета маршрутизатора (Rtr Pri, Router Priority) -  задается для интерфейса по которому маршрутизатор отправляет LSA8 в канал.* Поле Options имеет формат аналогичный LSA2, но применяется для канала.* Поле Link-local Interface Address содержит адрес интерфейса маршрутизатора передающего LSA8 на канале.* # prefixes - число префиксов IPv6 адресов содержащихся в LSA. Перечень префиксов связан с каналом.* Поля PrefixLength, PrefixOptions и Address Prefix соответствуют LSA3.</text>
