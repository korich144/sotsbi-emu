<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1496236822">LSA1 - Router-LSA: * Бит x - ранее применялся как бит W (wild-card multicast receiver) который означал, что маршрутизатор должен принимать многоадресную (групповую) рассылку, когда запущен Multicast OSPF, вне зависимости от их назначения.   Бит x должен быть установлен в нулевое значение и игнорироваться при приеме. Возможно в будущем он будет переназначен.* Бит Nt устанавливается когда маршрутизатор является NSSA BR и переводит NSSA-LSA в LSA5 (AS-external-LSAs), то есть осуществляет NSSA трансляцию. Каждый такой маршрутизатор должен быть настроен таким образом чтобы параметр NSSATranslatorRole имел значение Always.* Установка бита V (virtual link endpoint) означает наличие нескольких соединений смежности (adjacent), определяющих зону как транзитную.* Установка бита E (external) означает, что маршрутизатор является ASBR.* Установка бита B (border) означает, что маршрутизатор является ABR.* Поле Options применяется для поддержания необязательных возможностей и передачи их другим маршрутизаторам OSPF. В Options могут применяться следующие биты:- V6-bit (IPv6) - если бит имеет нулевое значение (не установлен), то маршрутизатор (или соединение) должно быть исключено из IPv6 маршрутизации.- E-bit (external) - установка бита сообщает о том, что разрешена передача внешних LSA5 (AS-external-LSAs) - MC-bit (multicast) - установка бита, означает разрешение передачи многоадресной рассылки IP.  - N-bit - установка бита, сообщает о обработке LSA тип 7.- R-bit (router) - определяет является ли отправитель активным маршрутизатором. Если бит имеет нулевое значение, то маршруты передаваемые анонсирующим (advertising) узлом не могут быть вычислены. Нулевой бит применяется многоуровневым маршрутизатором, который принимает участие в маршрутизации, но не хочет пересылать пакеты, адресуемые не только ему.- DC-bit (demand circuits) - определяет использование маршрутизатором полупостоянных и коммутируемых соединений (demand circuits), например, ISDN, X.25, и аналоговых телефонных линий.* Поле Type - определяет тип интерфейса: 1) соединение точка-точка с другим маршрутизатором; 2) соединение к транзитной сети (Connection to a transit network); 3) Зарезервировано; 4) Виртуальное соединение (Virtual link).* Поле Metric - задает стоимость использования интерфейса для исходящего трафика.* Поле Interface ID - идентификатор указывающий на интерфейс.* Поле Neighbor Interface ID - идентификатор интерфейса соседнего маршрутизатора (для Type 2, соединение к DR) передаваемый в Hello-пакетах по соединению. * Поле Neighbor Router ID - идентификатор соседнего маршрутизатора (для Type 2, соединение к DR). Для Type 2 соединений, Neighbor Interface ID и Neighbor Router ID позволяют найти LSA2 (network-LSA) в LSDB.</text>
