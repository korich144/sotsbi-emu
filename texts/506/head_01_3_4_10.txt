<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1536153837">Помимо сигнальной информации по сети NGN необходимо передавать пользовательские  данные, например,  речь. Для организации взаимодействия телефонной сети и сети NGN нужно преобразовать речь из TDM технологии в  пакеты для  передачи  по сети IP, на которой  используются  другие кодеки,  другие системы передачи информации. Эти задачи решаются в шлюзах AGW и TGW. Для трансляции речи по сети NGN используется протокол RTP (Real Time Protocol). С помощью протокола RTP пользовательская  информация (речь, данные) транслируется  по сетям UDP/TCP/IP. Так же как для протокола  IP используется ICMP,  для протокола RTP используется протокол RTCP (Real Time Control Protocol), который передает информацию о процессе передачи (наличие ошибок, потерь). RTCP обеспечивает  мониторинг работы протокола RTP.  Качество передачи пакетов  отражается в сообщениях RTCP и, в случае больших потерь, оборудование может перестроиться и перейти на другие кодеки, использовать другую полосу пропускания для передачи пользовательской информацию с более высоким качеством.</text>
