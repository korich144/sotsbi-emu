При отсутствии каких-либо критических ошибок (из числа описанных ранее) узел BGP может в любой момент закрыть соединение BGP, передав партнеру сообщение NOTIFICATION с Error Code = Cease.Узел BGP может принять решение о разрыве соединения BGP со своим соседом в результате получения от того избыточного числа префиксов, тогда узел должен передать соседу сообщение NOTIFICATION с Error Code = Cease.</text>
