Сервер, с которого загружаются апплеты, должен быть доверенным. 
Апплет должен выполняться в среде с ограничениями, позволяющими выполнять только те функции, которые не влияют на безопасность. 
Апплет должен быть проверен на безопасность перед выполнением. 
Скрипты интерпретируются, а не являются предварительно скомпилированными. Поэтому есть риск, что скрипт может быть модифицирован при передаче по сети и не будет выполнять свои функции.
Java содержит в своем составе набор стандартных функций «библиотеки классов». 
В комплекте со всеми средствами разработки Java поставляются достаточно развитые библиотеки классов, значительно упрощающие программирование. Например,  Класс String предназначен для работы с такими объектами, как текстовые строки. Методы, относящиеся к этому классу позволяют выполнять над строками практически все операции. Это преобразование строки в число и обратно с любым заданным основанием, определение длины строки, сравнение строк, извлечение подстроки и так далее.</text>
