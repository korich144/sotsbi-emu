<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Ожидаемое время раскрытия пароля можно вычислить по формуле 1.
Сам пароль и отдельные ограничения должны храниться в секрете. Поэтому база учетных данных системы защиты должна быть криптографически закрытой. На компьютерах с ОС семейства UNIX, базой является файл /etc/master.passwd, на компьютерах с операционной системой Windows NT/2000/XP/2003 (не входящих в домен Windows) такая база данных называется SAM (Security Account Manager). Следует осуществлять динамический контроль эталонного состояния компьютера пользователя для недопущения перехвата пароля в процессе аутентификации непосредственно на этой рабочей станции. Такой перехват может быть выполнен с помощью программной закладки, активизированной на рабочей станции в процессе загрузки операционной системы. Кроме того, для исключения возможности перехвата многоразового пароля в сети его нельзя передавать по линиям связи в открытом виде.</text>
