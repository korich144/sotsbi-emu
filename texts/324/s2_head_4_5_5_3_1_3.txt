<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">SecurityManager вызывается виртуальной машиной Java для проверки ряда специфичных действий. Ниже приведены некоторые общие (public) методы, которые вызывает SecurityManager для таких проверок.
CheckCreateClassLoader - Проверка предотвращения установки дополнительного ClassLoader
CheckAccess - Проверка может ли thread или thread группы изменять thread группы
CheckExit - Проверка возможности выполнения команды Exit
CheckExec - Проверка возможности выполнения системных команд
CheckLink - Проверка возможности связывания (link) динамических библиотек (используется для локального кода)
CheckRead - Проверка возможности чтения файла
CheckWrite - Проверка возможности записи в файл
CheckConnect - Проверка возможности создания сетевых соединений
CheckListen - Проверка открытия сетевого порта
CheckAccept - Проверка возможности работы с сетью
CheckPackageAccess - Проверка возможности обращения к package
CheckPackageDefinition - Проверка возможности добавления нового класса к package
SecurityManager управляет доступом к критическим ресурсам системы.</text>
