<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Вторая группа - контроль при получении и загрузке программ.
Контроль при получении и загрузке программ носит в Java многоступенчатый характер.
- Во-первых, программные компоненты могут снабжаться электронной подписью, что позволяет контролировать их целостность и аутентичность.
Технология Java использует для криптографической аутентификации механизм JAR, а технология ActiveX – механизм Authenticode. Для языка сценариев JavaScript компании Netscape также имеется возможность подписи кода (object signing).
Альтернативным подходом по отношению к подписанию кода является механизм защиты соединения между Web-сервером и браузером (при помощи протокола SSL или другого иного). Криптографический сертификат сервера может быть запрошен при выполнении мобильным кодом некоторых дополнительных действий. Данный подход имеет свои преимущества по сравнению с подписью кода:
В случае, когда необходима аутентификация не только кода, но и страниц Web-сервера использование одного механизма защищенного соединения более доступно и просто, чем использование двух механизмов подписи кода и страниц;
Это обязательное требование для мобильного кода, которому требуются привилегии, большие по сравнению с предоставляемыми системой защиты по умолчанию. Кроме того, защищенное соединение требуется, когда необходимо обеспечить надежную обратную связь с местом получения кода;
Действие элементов управления может быть отменено в любое время, и они могут быть удалены из всех компьютеров сети без потери функциональности;
Злоумышленник не может многократно использовать враждебный мобильный код (апплеты), т.к. он непосредственно не подписывается. Для этого нарушитель должен иметь доступ к защищенному серверу.
Защищенное соединение является самостоятельным механизмом защиты, которое дополняет механизмы криптографической аутентификации и верификации мобильного кода. От используемых технологий данный механизм не зависит и может быть использован для защиты мобильного кода написанного как при помощи Java, так и при помощи ActiveX.</text>
