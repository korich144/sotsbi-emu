<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">При использовании протокола SIP для установления сессии, по IP сети  может передаваться любая пользовательская информация: речь, видео, данные; а так же их комбинация, называемая мультимедийной информацией. При установлении сессии между терминалами необходимо известить их, какого рода информация может передаваться/приниматься, алгоритмы ее кодирования, адрес, на который она будет передаваться и другие параметры. Для этой цели в сообщение SIP, в качестве тела сообщения, вставляется описание сеанса связи с использованием протокола SDP (Session Description Protocol).
Для передачи мультимедийной информации комитет IETF (Internet Engineering Task Force) предлагает использовать протокол RTP (Real Time Protocol), но сессия установленая с использованием протокола SIP может быть организована с использованием других протоколов передачи мультимедийной информации.
Доставка пакетов RTP контролируется протоколом RTCP (Real Time Control Protocol).</text>
