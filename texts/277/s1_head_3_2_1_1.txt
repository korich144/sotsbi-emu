<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Прикладной – обеспечивает управление взаимодействием прикладных процессов. Прикладной уровень является интерфейсом между приложением и самой моделью. На этом уровне производятся первичные действия по подготовке информации для передачи по сети, включая идентификацию получателя и его доступность. Этот уровень обрабатывает и надлежащим образом форматирует данные, а затем передает их вниз, на следующий уровень модели OSI. Протоколами, работающими на этом уровне, являются, например, HTTP (Hypertext Transfer Protocol - Протокол передачи гипертекста), FTP (File Transfer Protocol - Протокол передачи файлов), TFTP (Trivial File Transfer Protocol - Простой протокол передачи файлов) и т.д.
На Рисунке показано, как приложения взаимодействуют с нижестоящими протоколами посредством интерфейсов программирования приложений API (Application Programming Interface). Если пользователь создает запрос на отправку сообщения электронной почты через почтовый клиент, то почтовый клиент отправляет эту информацию по протоколу SMTP. SMTP добавляет свою информацию к пользовательской информации и отправляет ее вниз на представительский уровень.
