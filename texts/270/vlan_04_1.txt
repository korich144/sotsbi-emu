<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Порт коммутатора обрабатывающий трафик с тегами VLAN можно настроить в один из 3х режимов: Access, Trunk, Hybrid. 
Access порт (порт доступа) - применяется для подключения пользователей. Все кадры с пользовательской стороны получают тег VLAN заданного для этого порта. Считается что пользователь отправляет кадры без тегов VLAN.
Trunk порт (транкинговый порт) - применяется для пропуска тегированного трафика между коммутаторами. Все кадры между коммутаторами имеют теги полученные на портах доступа, за исключением сигнального трафика. На портах настраиваются идентификаторы VLAN, которые разрешается передавать. Указывается тег VLAN для кадров без тега.
Hybrid порт (гибридный порт) - применяется как универсальный порт. На порте настраиваются идентификаторы VLAN, которые разрешается передавать. Все кадрый попадающие на данный порт без тега, получают тег VLAN.</text>
