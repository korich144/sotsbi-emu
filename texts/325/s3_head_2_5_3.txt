<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Асимметричная криптография (с открытым ключом) использует два ключа (открытый и секретный), она применяется для защиты ключей шифрования и их распространения. Секретный ключ используется для основного процесса шифрования симметричным алгоритмом. В этом и заключается гибридное использование двух различных алгоритмов: симметричного и асимметричного. Каждый алгоритм имеет свои преимущества и недостатки, а их совместное использование позволяет взять лучшее от каждого из них.
Секретный ключ используется для шифрования отправляемых сообщений симметричным алгоритмом. Получателю зашифрованного сообщения нужно расшифровать его, для чего требуется симметричный ключ, на котором зашифровано сообщение. Для обеспечения защиты этого ключа можно использовать асимметричный алгоритм, с помощью которого он может быть зашифрован.
Асимметричный алгоритм работает медленно, т.к. он использует более сложную математику. Поскольку отправляемое сообщение, скорее всего, будет длиннее ключа, для его шифрования разумнее использовать более быстрый симметричный алгоритм, а для шифрования ключа подойдет медленный асимметричный алгоритм, обеспечивающий дополнительные возможности безопасности.</text>
