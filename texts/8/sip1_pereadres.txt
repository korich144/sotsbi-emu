<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Сервер переадресации предназначен для определения текущего адреса вызываемого пользователя. Вызывающий пользователь передает к серверу сообщение с общеизвестным адресом вызываемого пользователя, а сервер обеспечивает переадресацию вызова на текущий адрес этого пользователя. Для реализации этой функции сервер переадресации должен воспользоваться услугой определения местонахождения. Сервер переадресации не содержит клиентскую часть программного обеспечения. В случае если текущий адрес вызываемого пользователя известен, сервер переадресации не используется. </text>
