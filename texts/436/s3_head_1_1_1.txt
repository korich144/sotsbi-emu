<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Протокол TFTP имеет «клиент-серверную» архитектуру. Обмен данными между клиентом и сервером начинается с того, что клиент запрашивает сервер либо прочитать, либо записать файл для клиента. Если сервер положительно реагирует на запрос, то соединение открывается и файл (или почта) пересылается в стандартных блоках по 512 байт.
Для TFTP определено 5 видов сообщений:
•RRQ  (Read Request) - запрос на чтение файла. Используется для скачивания файлов с TFTP сервера;
•WRQ (Write Request) - запрос на запись файла. Используется для записи файла на TFTP сервер;
•DATA - данные, передаваемые через TFTP. Используется непосредственно для передачи данных от клиента к серверу и обратно.
•ACK (Acknowledgment) - подтверждение блока данных. Используется для подтверждения, что предыдущий передаваемый блок данных был успешно принят получателем (или что сервер может осуществить запись файла).
•ERR (Error) — ошибка. Используется для указания, что на предыдущем шаге работы протокола произошла ошибка, например отсутствовал запрашиваемый файл, или же отсутствовало разрешение на его чтение.</text>
