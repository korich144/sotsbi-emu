<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Поле Идентификатор приложения (Application-ID) состоит из четырех октетов и используется для идентификации приложения, к которому относится передаваемое сообщение. Приложением в данном случае может быть приложение аутентификации, приложение учета, или приложение, специфическое для производителя. Значение поля идентификатора приложения в заголовке должно совпадать со значением, передаваемым в соответствующей AVP этого сообщения.
Определены следующие значения идентификаторов:
• базовый протокол Diameter	 0
• приложение сервера доступа к сети 	 1
• приложение Mobile-IP	 2
• учет базового протокола Diameter 	3
• приложение ретрансляции 	0xFFFFFFFF
