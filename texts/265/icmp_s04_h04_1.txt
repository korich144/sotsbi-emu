<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|" uts="1502440822">Утилита Ping нужна для проверки возможности соединения с другой системой. Она отправляет проверяемой системе сообщение ICMP ECHO REQUEST (тип 8), а в ответ ожидает сообщение ICMP ECHO REPLY (тип 0), получение которого Ping отображает на экране. При этом с помощью DNS утилита Ping узнает ip адрес проверяемого узла, в случае в команде использовалось доменное имя и отображает его на экране. Кроме того на экране для каждого пакета указывается значение поля времени жизни пакетов (TTL) и время двусторонней (круговой) задержки. Иногда утилита отправляет сразу 3 пакета одновременно и тогда в каждой строчке указывается дополнительно минимальное, максимальное и среднее значение двусторонней задержки. Каждое сообщение ECHO REQUEST содержит в поле данных случаный набор hex-кода, который возвращается в ECHO REPLY для проверки искажений передаваемых данных. Количество байт тестовых данных указывается на экране. По завершению отправки сообщений, утилита Ping выводит итоговые для всех пакетов значения потерь, и значения двусторонней задержки (минимальное, среднее и максимальное).Если ответ не был получен в течение определенного периода времени, утилита Ping повторно отправляет кадры ECHO REQUEST. Если ответа снова нет, утилита Ping сообщает, что проверяемая система недоступна.</text>
