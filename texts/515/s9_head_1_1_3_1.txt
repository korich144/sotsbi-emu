<?xml version="1.0" encoding="UTF-8" ?><text>Сообщения HTTP могут передаваться через посредников для передачи сообщений через цепочку соединений. Существует три вида посредников HTTP: прокси, шлюз и туннель. В разных случаях один и тот же посредник может выступать в роли сервера, прокси, шлюза или туннеля, меняя поведение в зависимости от запроса.  Например, имеется клиент (UA, user agent), сервер (O, origin server), и три посредника (A, B и C) между ними. Сообщение HTTP должно пройти по цепочке из четырех соединений. Некоторые опции взаимодействия HTTP могут использоваться только в одном из соединений между соседними узлами, между конечными узлами или между любыми соединениями в цепочке.</text>
