<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Сообщения протокола HTTP принадлежать к одной из двух больших групп: запросов и ответов. Запросы содержат тип запроса и URI указывающий на запрашиваемый ресурс. Основные типы запросов описаны в RFC-7231, их принято так же называть методы доступа.  Указатель метода (тип запроса) всегда должен писаться заглавными буквами.  Для получения ресурса применяется метод GET. Для получения только информации о ресурсе применяется метод HEAD. С помощью него можно узнать время изменения документа, его размер и тип. Метод POST используется для отправки данных на сервер для обработки с целью создания нового ресурса. Метод PUT заменяет указанный в запросе ресурс на данные из тела сообщения. Метод DELETE указывает на ресурс, который должен быть удален. Метод CONNECT устанавливает туннельное соединение к серверу, содержащему ресурс. Метод OPTIONS запрашивает параметры и возможности сервера для указанного ресурса. Метод TRACE позволяет проверить отправку и прием сообщений вдоль всего пути от отправителя к целевому ресурсу. Метод PATCH описанный в RFC-5789, в отличие от PUT, позволяет дополнить существующий ресурс, тогда как PUT полностью обновил бы ресурс.</text>
