<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">При использовании DNS, применяются настройки из файла /etc/resolv.conf, в котором содержится информация о DNS-серверах. Порядок, в котором перечислены сервисы, определяет последовательность их опроса. Например, с помощью команды cat можно получить содержимое /etc/resolv.conf . Параметр nameserver определяет IP-адрес сервера доменных имен, на который будет отправлен DNS-запрос. Если сервер с адресом 172.16.117.21 не сумеет обработать запрос, то запрос будет отправлен на следующий сервер с адресом 172.16.117.41. Параметр domain определяет заданное по умолчанию имя домена (ip.lab), которое будет подставлено, если DNS не удастся найти имя хоста. Также может быть задан параметр search, в котором указываются дополнительные домены поиска. Параметры search и domain нельзя использовать совместно.</text>
