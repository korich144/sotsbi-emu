<?xml version="1.0" encoding="UTF-8" ?><text>Первоначально с помощью HTTP передавался только текст в формате HTML. С развитием веб-технологий с помощью HTTP стали передаваться изображения, таблицы стилей, звук, видео и другая информация. Некоторые протоколы используют HTTP в качестве транспорта.  HTTP простой, расширяемый и распространенный.  Легко можно создать приложение работающее с протоколом HTTP. Протокол позволяет внедрять в текст сообщений свои собственные заголовки, необходимые для решения специфических задач. При этом совместимость с другими серверами и клиентами не потеряется, так как они будут игнорировать неизвестные им заголовки. HTTP получил широкое распространение – через него передается наибольшее количество трафика, который генерируют веб-приложения.</text>
