<?xml version="1.0" encoding="UTF-8" ?><text>HTTP/2 использует ту же URI-схему, что &quot;http&quot; и &quot;https&quot;, реализуемую в HTTP/1.1. HTTP/2 использует тот же номер порта по умолчанию: 80 для URI http и 443 для URI &quot;https&quot;. Поэтому при запросах http://example.org/foo или https://example.com/bar требуется определение поддержки версии 2. Если заранее не определено использование HTTP/2, клиент отправляет запрос HTTP/1.1, который включает поле заголовка Upgrade с лексемой &quot;h2c&quot;, применяя механизм HTTP Upgrade. Такой HTTP/1.1 запрос должен включать только одно поле заголовка HTTP2-Settings. Сервер с поддержкой HTTP/2, воспринимает upgrade с ответом 101 (Switching Protocols). После пустой строки в ответе 101, сервер может начать посылку кадров HTTP/2. Эти кадры должны включать ответ на запрос, который запустил Upgrade. Если сервер не поддерживает HTTP/2, то он игнорирует заголовок Upgrade, и отправляет ответ 200 OK. Кроме того для перехода на другой протокол может использоваться запрос OPTIONS.</text>
