<?xml version="1.0" encoding="UTF-8" ?><text src="dbbgn 0.000|">Код 51 IP address Lease Time – время аренды IP-адреса. В DHCP предусмотрены еще два таймера: Код 58 Renewal (T1) Time Value – таймер выдержки перед началом обновления параметров, после получения DHCP-ACK, равный половине времени аренды. Код 59 Rebinding (T2) Time Value – таймер неответа DHCP-сервера на запрос обновления параметров, равный 7/8 времени аренды, после которого инициируется широковещательная отправка сообщения DHCP request для поиска DHCP-сервера. Код 53 DHCP Message Type – тип сообщения DHCP. Код 54 Server Identifier – идентификатор сервера. Код 61 Client-identifier – идентификатор клиента. Код 55 Parameter Request List – список запрашиваемых параметров. Код 0 Pad - Заполнитель для параметров переменной длины по границе слова. Код 255 End – конец необязательных параметров.</text>
