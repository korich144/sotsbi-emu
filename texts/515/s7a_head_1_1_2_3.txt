<?xml version="1.0" encoding="UTF-8" ?><text>Протоколы маршрутизации можно разбить на две группы: это протоколы внутреннего шлюза (IGP, Interior Gateway Protocol), предназначенные для работы в сравнительно небольших сетях, и протоколы внешнего шлюза (EGP, Exterior Gateway Protocol), предназначенные для обмена маршрутами в сети интернет. К протоколам IGP относятся такие протоколы как Routing Information Protocol (RIP), Open Shortest Path First (OSPF), Intermediate System-to-Intermediate System (ISIS) и Enhanced Interior Gateway Routing Protocol  (EIGRP). В качестве протокола внешнего шлюза используется протокол Border Gateway Protocol (BGP).
</text>
