<?xml version="1.0" encoding="UTF-8" ?><text>Другим популярным языком разметки данных является JSON (JavaScript Object Notation), описанный в RFC-7159. Текстовый формат JSON основан на языке JavaScript (на его стандарте ECMA-262 от 1999 года). JSON представляет собой одну из двух структур: либо набор пар «ключ: значение», либо упорядоченный набор значений в квадратных скобках. С помощью языка JSON могут быть описаны такие структуры как объект, массив, число, литералы (true, false, null) и строки. </text>
